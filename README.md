## 仓库结构

```
.
├── README.md
├── 机器学习概述/
│   ├── 机器学习概述.md
│   └── images/          # 该笔记引用的全部插图
├── KNN算法/
│   ├── KNN算法.md
│   └── images/
└── ...
```

每篇笔记与其 `images/` 目录放在同一主题文件夹内，笔记中的图片均使用相对路径 `images/xxx.png` 引用，因此在 GitHub 或任意 Markdown 编辑器中打开都能正常显示。
